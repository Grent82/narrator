**Warum:** In dieser Session wurde mehrfach angenommen statt nachzufragen:
1. Frontend-Integration wurde nicht geklärt bevor Backend-Features implementiert wurden
2. Fuzzy-Matching wurde vorgeschlagen statt zu prüfen wo Lore generiert wird
3. Story Generator wurde nicht geprüft bevor Lösungen vorgeschlagen wurden

**How to apply:**
- Bevor Features implementieren: Immer erst Frontend-Struktur prüfen
- Bevor Lösungen vorschlagen: Immer erst relevanten Code lesen
- Bei Unsicherheit: AskUserQuestion statt Annahmen
- "Backend first" ist gefährlich - ganzheitlich denken
